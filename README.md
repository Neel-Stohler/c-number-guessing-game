
# Number Guessing Game

A simple number guessing game written in C.

## About

The program generates a random number between 1 and 10. The player has three attempts to guess the correct number.

The game provides hints to help the player find the correct number.

## Features

- Random number generation
- Three attempts per game
- Hints for higher or lower guesses
- Input validation
- Personalized greeting

## Technologies

- C
- CS50 Library
- GCC

## How to Run

Compile the program:

```bash
gcc guessing.c -o guessing -lcs50
```

Run the game:

```bash
./guessing
```
